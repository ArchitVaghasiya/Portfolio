# Archit Vaghasiya Portfolio

A responsive student portfolio for Archit Vaghasiya, a Computer Engineering student at CHARUSAT University.

## Features

- React Router pages for Home, Projects, and Contact
- Reusable Header, About, Skills, Footer, and navigation components
- Controlled contact form with a toggleable help message
- GitHub repository viewer with loading and error states
- Responsive styling and accessible contact icons

## Tech stack

- React
- Vite
- React Router
- GitHub REST API

## Run locally

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
